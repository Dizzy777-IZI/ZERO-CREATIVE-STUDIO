# ZERO — Panduan Ekspor Sosial Media

Pengaturan berikut adalah titik awal, bukan jaminan spesifikasi platform terbaru.

## Video vertikal
- Rasio umum: 9:16.
- Resolusi target umum: 1080 × 1920 jika sumber mendukung.
- Kontainer distribusi umum: MP4.
- Codec umum: H.264; audio AAC bila kompatibel.
- Pertahankan frame rate sumber bila sesuai.
- Tempatkan teks penting di area aman dan uji pada layar ponsel.

## Sebelum ekspor
Konfirmasi platform, durasi, resolusi sumber, frame rate, orientasi, kebutuhan subtitle, cover, audio, dan tujuan publikasi. Periksa dokumentasi platform terbaru bila angka batas atau persyaratan wajib diperlukan.

## Setelah ekspor
Putar file hasil, periksa audio-sync, subtitle, frame awal/akhir, transisi, rasio, resolusi, frame rate, codec, dan ukuran file. Jangan mengklaim lulus QC bila file belum ditinjau.
