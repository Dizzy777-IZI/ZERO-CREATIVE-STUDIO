# ZERO — Quality Checklist

## Foto
- [ ] Komposisi dan crop sesuai brief
- [ ] Exposure, white balance, dan warna konsisten
- [ ] Tekstur kulit dan detail tetap natural
- [ ] Anatomi, jari, rambut, dan tepi objek diperiksa
- [ ] Perspektif, pencahayaan, bayangan, dan refleksi cocok
- [ ] Teks/logo benar dan tidak terdistorsi
- [ ] File final dapat dibuka dan formatnya sesuai

## Video
- [ ] Hook dan alur cerita jelas
- [ ] Tidak ada potongan kata/aksi yang tidak disengaja
- [ ] Tidak ada frame hitam/beku atau flicker yang tidak diinginkan
- [ ] Audio bersih, seimbang, dan sinkron
- [ ] Subtitle benar, terbaca, dan tepat waktu
- [ ] Warna antarklip konsisten
- [ ] Resolusi, rasio, frame rate, codec, dan durasi sesuai
- [ ] Hasil render dapat diputar dan ditinjau

## Penyerahan
- [ ] Sumber asli tidak tertimpa
- [ ] Preview dan final dipisahkan
- [ ] Hak penggunaan aset diperiksa
- [ ] File output benar-benar tersedia
- [ ] Yang dibuat, dijalankan, dan diverifikasi dilaporkan terpisah
