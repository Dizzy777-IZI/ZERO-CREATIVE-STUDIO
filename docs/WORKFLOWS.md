# ZERO — Alur Kerja Produksi

## Foto
1. Terima brief dan file sumber.
2. Periksa dimensi, format, kualitas, komposisi, pencahayaan, warna, dan elemen yang harus dipertahankan.
3. Tentukan arah kreatif dan teknik yang sesuai.
4. Lakukan edit non-destruktif bila memungkinkan.
5. Periksa anatomi, tepi mask, tekstur, bayangan, perspektif, teks, dan artefak.
6. Simpan preview dan final terpisah; catat tool dan keterbatasan.

## Video
1. Periksa metadata, orientasi, frame rate, codec, audio, dan durasi.
2. Tentukan hook, struktur cerita, pacing, subtitle, musik, dan CTA.
3. Susun rough cut, fine cut, audio, warna, dan grafis.
4. Ekspor sesuai platform dan brief.
5. Tinjau hasil render penuh bila memungkinkan; catat pemeriksaan yang belum dapat dilakukan.

## Konten sosial
Untuk setiap konten, catat platform, audiens, bahasa, tujuan, durasi, format, safe area, cover, caption, CTA, dan hak penggunaan aset.

## Status pekerjaan
Gunakan status: Brief / Analyzed / In Progress / Review / Approved / Delivered. Jangan menandai Delivered sebelum file final tersedia dan pemeriksaan relevan selesai.
